# Yashwanth Venaganti — Portfolio

Static, responsive portfolio website with a custom CSS 3D hero object, interactive pointer tilt, scroll reveals, mobile navigation, project cards, and contact links.

## Run locally
Open `index.html` in a browser. No build step or dependencies are required.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of a GitHub repository.
2. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
3. The site will be served from `https://<username>.github.io/<repository>/`.

Project preview art is original CSS artwork designed to represent the named projects; it is not copied from third-party sites.
